# Remote server

No GPU server is implemented in this repository. The supported desktop-client
contract is [`../docs/REMOTE_IQA_CONTRACT.md`](../docs/REMOTE_IQA_CONTRACT.md), and
real GPU/SMB validation remains deferred to
[`../docs/exec-plans/deferred/p5g-external-gpu-smb-validation.md`](../docs/exec-plans/deferred/p5g-external-gpu-smb-validation.md).

[`api_contract.md`](api_contract.md) is retained only as the historical pre-P5 API
scaffold from the initial repository release. It is not a supported endpoint or schema
contract.
