# Inspect a Line Profile

Line Profile plots sample values along a shared horizontal or vertical line.

## Create a line

1. Open **Plots > Line Profile**.
2. In Image View, **Shift+drag** to define the line.
3. PixelScope shows the line coordinates and plots compatible sources from the Current Comparison Page.

The shared line uses source/reference coordinates so that the same spatial location can be compared across the current page.

## Clear the line

Use **Edit > Clear Line**. When the Line Profile tab is current, `Shift+Esc` clears the line profile.

A context change that makes the line invalid can clear it rather than silently remapping it to unrelated coordinates.

## Troubleshooting keywords

**Shift+drag**, **Shift+Esc**, **clear line**, **line profile empty**, **line coordinates**.
