# Curate a Large Selection

Use **Pick** when you want to inspect a large Selected set page by page and reduce it to a smaller comparison subset. There is no separate review mode to enter.

## Start picking

1. Show the large Selected set in Multi View.
2. Move through Comparison Pages.
3. Use the **Pick** control on each source you want to keep.
4. The presentation row reports the temporary picked count.

The first Pick captures the current selection as the temporary curation baseline. Pick membership persists while you move between Comparison Pages.

## What does not change Pick

Ordinary image activation, pan, ROI drawing, and Line Profile gestures do not toggle Pick. Pick is an explicit curation action, separate from **Active** and **Primary**.

## Keep Selection

Use **Keep Selection** to replace the logical Selected set with the picked subset, preserving baseline order. If nothing is picked, Keep Selection remains unavailable rather than clearing the comparison accidentally.

Use **Clear Selection** to clear the temporary picks without changing the underlying source files.

A separate operation that replaces Selected membership can invalidate the temporary curation baseline so stale picks are not applied to a different selection.

## Analysis scope

Pick does not expand Statistics, Histogram, or Line Profile beyond the Current Comparison Page. Picking also does not itself load images, calculate Difference, or make picked off-page sources resident merely because they are picked.

## Troubleshooting keywords

**Pick**, **Picked N**, **Keep Selection**, **Clear Selection**, **curation**, **more than six images**.
