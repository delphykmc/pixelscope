# Histogram

Histogram is the distribution view in the Plots workspace.

<!-- pixelscope:screenshot histogram-docked -->

## Scope

Histogram analyzes the Current Comparison Page. It uses the full image when no ROI is active and the shared ROI when one is set. The controls identify the analysis region so the plotted distribution can be interpreted without guessing its spatial scope.

## Channels

Channel controls follow source semantics. RGB, Gray/Bayer, and native YUV sources do not necessarily expose the same channel set.

## When to use it

Use Histogram to compare exposure/value distributions, clipping, channel balance, or distribution changes between sources. Use Statistics for scalar summaries and Line Profile for spatial variation.
