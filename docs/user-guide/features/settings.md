# Settings

<!-- pixelscope:screenshot settings-dialog -->

Settings contains persistent application preferences. Open **Edit > Settings...**.

## Core categories

The current core settings cover **General**, **Files & Recent**, and **Performance**. General includes startup/view defaults and Difference defaults. Files & Recent controls recent-entry behavior. Performance controls source and Difference cache budgets, preload, and worker limits.

Some settings can apply immediately while resource-budget or runtime-lifecycle changes may require restart; follow the status shown by the dialog.

Deployments that enable Remote IQA integration may expose additional IQA configuration through the composed application.

For field-level guidance, see [Settings reference](../reference/settings.md).
