# Standard Images

PixelScope directly supports common standard-image files used by the local comparison workflow.

## Supported extensions

- `.png`
- `.bmp`
- `.jpg`
- `.jpeg`

Open them with **Open Images** or discover them through **Open Folder**. Standard images do not require the RAW profile dialog.

## Analysis

Decoded channel semantics determine whether a source is treated as Gray or RGB/RGBA for Statistics, Histogram, Line Profile, and Difference. Alpha is not treated as a Difference color channel.

For the complete extension/interpretation table, see [Supported formats](../reference/supported-formats.md).
