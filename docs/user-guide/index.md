# PixelScope User Guide

PixelScope is a desktop image comparison and analysis tool for quickly registering many images, selecting a working set, inspecting image data, and comparing results numerically and visually.

This guide is organized around **what you want to do**, not around PixelScope's implementation. Use the search box for commands, concepts, formats, and troubleshooting terms.

## Start here

New users should follow the [Quick start](getting-started/quick-start.md). It covers the shortest path from opening files to Statistics, Histogram, Line Profile, and Difference.

If a workflow uses unfamiliar terms such as **Registered**, **Selected**, **Current Comparison Page**, **Active**, **Primary**, or **Folder Position**, read [Core concepts](getting-started/concepts.md) first.
